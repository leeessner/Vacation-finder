# Travel legs and timings

One file per plan (same name, `.yaml`). The trip page shows `legs` under the
price, in order with the flights, and adds each `timed` entry under its day
in the day-by-day plan. Day 1 is the first night's check-in; dates follow
the trip's tracked dates. All times are local and **typical**: check the
real timetable when booking. See `src/vacation_finder/journey.py`.
